# مذكرتي — النسخة الاحترافية
- صفحة رئيسية RTL أبيض + زيتي + وضع داكن.
- نموذج طلب عميل يحفظ الطلبات.
- لوحة تحكم Admin خاصة بالمالك.
- إدارة محتوى الصفحة، الخدمات، الأعمال، وطلبات العملاء.
- SQLite للتخزين.

## التشغيل
Node.js 18+ ثم:
npm install
انسخ .env.example إلى .env وعدّل بيانات الدخول.
npm start
الموقع: http://localhost:3000
الأدمن: http://localhost:3000/admin/

غيّر كلمة المرور وSESSION_SECRET قبل النشر، واستخدم HTTPS في الإنتاج.

## لوحة الأدمن الجديدة
- تسجيل دخول خاص بالمدير.
- Dashboard بإحصائيات الطلبات وحالتها.
- البحث والتصفية داخل الطلبات + نافذة تفاصيل + تغيير الحالة + فتح واتساب.
- إدارة معرض الأعمال مع رفع الصور من الجهاز.
- إدارة الأسعار والباقات والخدمات.
- تعديل نصوص الموقع من لوحة التحكم.
